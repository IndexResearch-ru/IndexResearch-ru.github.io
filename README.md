## Товарные подборки Марии Яковлевой

Раздел [«Товары»](https://indexresearch.ru/products/) предназначен для авторских подборок товаров с реферальными ссылками Марии Яковлевой.

**Для Work-чатов и публикующих агентов:** перед новой подборкой прочитать [единый рабочий стандарт](docs/PRODUCT_SELECTIONS_WORKFLOW.md) и [AGENTS.md](AGENTS.md). Стандарт описывает проверку точных моделей и источников, 1 фото каждого товара, сохранность ссылок, 3 GitHub README + 3 страницы сайта и подготовку материалов Sostav / TenChat. Статусы конкретных выпусков находятся в `docs/product-selections/`; наличие инструкции не означает, что первый выпуск уже опубликован.
