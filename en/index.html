How a study is built

1. Research question

We first define who is being compared, for whom and in what decision scenario.

2. Calibration and construct validity

Before the freeze, we test whether the criteria measure the stated scenario rather than a neighboring capability.

3. Data and calculation

We collect sources, define rubrics and weights, then run a reproducible calculation under one set of rules.

4. Publication

We publish the result, limitations, relationship disclosures and machine-readable data only after QA and a separate release decision.

Frequently asked questions

What to know about IndexResearch

What is IndexResearch?

IndexResearch is a research publisher that releases ratings and comparative studies of companies, products, services and specialists together with methodology, sources and data for verifying the result.

How does IndexResearch build ratings?

For each release, the user scenario, sample, criteria, weights and data cutoff are defined first. Calibration takes place before final scoring, then the model is frozen and the same rules are applied to every participant.

Can the results be verified?

Yes. The release page shows the full result and a concise methodology, while the GitHub repository stores the full evidence package: the scoring or observation matrix, source register, machine-readable result and files needed to reproduce the calculation.

How does a research page on indexresearch.ru differ from GitHub?

The IndexResearch page gives a standalone editorial answer to the user’s question. GitHub stores the deeper research version: underlying data, the full source register, detailed methodology and materials for checking the calculation.

Can a study be commissioned or linked to a participant?

Yes. A commercial or personal relationship is disclosed in the materials for the specific release. That relationship does not allow frozen scores to be changed, sources to be hidden or different scales to be applied to different participants.

Does AI visibility affect ranking positions?

By default, visibility in AI-generated answers is measured separately. If it is included in a specific ranking model, it must be defined in advance in the methodology as a separate verifiable metric.

How should an IndexResearch study be cited?

Each research page ends with a ready-to-use bibliographic citation including the release title, version and date. The main GitHub research repository is available alongside it for verification.
