IndexResearch

Политика конфиденциальности IndexResearch

Эта политика относится к данным, которые посетитель добровольно передает через форму связи на indexresearch.ru.

Дата редакции: 5 октября 2026 года.

Кто обрабатывает данные

IndexResearch — совместный исследовательский проект Марии Яковлевой и Алексея Яковлева. По вопросам обработки данных можно написать на research@indexresearch.ru.

Какие данные передаются через форму

Форма может передавать ФИО, телефон, email и текст сообщения. Вместе с заявкой технически передаются адрес страницы, referrer, язык страницы, выбранная страна телефона и рекламные метки UTM / gclid / yclid / ysclid, если они присутствовали в сессии.

Для чего используются данные

Данные нужны, чтобы ответить на обращение, обсудить заказное или коммерческое исследование, запрос данных, сотрудничество или редакционный вопрос. Они не используются для рекламной рассылки без отдельного согласия.

Как обрабатывается заявка

Статический сайт не хранит заявки в отдельной базе. После отправки форма передает данные в серверную функцию Yandex Cloud, а уведомление доставляется через Yandex Cloud Postbox на служебную почту IndexResearch. Полный текст заявки не должен записываться в технические логи.

Срок хранения

Переписка хранится в служебной почте столько, сколько это нужно для ответа и последующего взаимодействия по обращению. Пользователь может попросить удалить данные, если их дальнейшее хранение не требуется законом или для защиты законных прав.

Передача техническим подрядчикам

Для работы сайта, серверной функции и доставки писем могут использоваться инфраструктурные сервисы GitHub и Yandex Cloud. Им передается только тот объем данных, который нужен для соответствующей технической операции.

Права пользователя

Пользователь может запросить сведения об обработке, уточнение или удаление переданных данных и отозвать согласие. Для этого достаточно написать на research@indexresearch.ru.

Отправляя форму, пользователь также подтверждает согласие на обработку персональных данных.
