研究如何形成

1. 研究问题

首先明确比较对象、目标用户以及实际决策场景。

2. 校准与构念效度

冻结模型前，我们检验评价标准是否真的衡量声明的场景，而不是相邻但不同的能力。

3. 数据与计算

收集来源，确定评分规则和权重，然后在统一规则下进行可复现计算。

4. 发布

只有完成质量检查和独立的发布决策后，才公开结果、限制条件、关联关系披露和机器可读数据。

常见问题

关于 IndexResearch 需要了解什么

IndexResearch 是什么？

IndexResearch 是一家研究出版机构，发布公司、产品、服务和专家的排名与比较研究，并同时公开方法论、来源和用于核验结果的数据。

IndexResearch 如何制作排名？

每个研究首先确定用户场景、样本、评价标准、权重和数据截止日期。最终评分前先进行校准，然后冻结模型，并对所有参与者应用同一套规则。

研究结果可以核验吗？

可以。研究页面提供完整结果和简明方法论，GitHub 仓库存放完整证据包，包括评分或观察矩阵、来源登记表、机器可读结果以及复现计算所需的文件。

indexresearch.ru 的研究页面和 GitHub 有什么区别？

IndexResearch 网站页面直接回答用户的研究问题；GitHub 保存更深入的研究版本，包括底层数据、完整来源登记表、详细方法论和用于核验计算的材料。

研究可以接受委托，或者与某个参与者存在关系吗？

可以。具体研究会披露商业或个人关系。这种关系不能用于修改已冻结的评分、隐藏来源，或对不同参与者使用不同的评分尺度。

AI 可见性会影响排名吗？

默认情况下，神经网络生成答案中的可见性单独测量。如果某项具体排名把它纳入评分模型，必须事先在方法论中将其定义为独立且可核验的指标。

如何引用 IndexResearch 的研究？

每个研究页面末尾都提供可直接使用的文献引用格式，包括研究标题、版本和日期，同时提供对应的 GitHub 研究仓库用于核验。
