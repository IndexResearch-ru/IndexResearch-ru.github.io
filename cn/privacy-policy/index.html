IndexResearch 隐私政策

本政策适用于访问者通过 indexresearch.ru 联系表单自愿提交的信息。

生效日期：2026 年 10 月 5 日。

谁处理这些数据

IndexResearch 是由 Maria Yakovleva 和 Alexey Yakovlev 共同创立的研究项目。有关个人数据处理的问题，请发送邮件至 research@indexresearch.ru。

表单会提交哪些数据

表单可能提交姓名、电话号码、电子邮箱和留言。同时会提交页面 URL、referrer、页面语言、所选电话国家，以及会话中存在的 UTM / gclid / yclid / ysclid 等来源参数。

数据用途

这些数据用于回复咨询，并讨论委托研究、商业研究、数据请求、合作或编辑相关问题。未经单独同意，不会用于营销邮件。

请求如何处理

静态网站本身不建立独立的潜在客户数据库。表单会把请求发送到 Yandex Cloud 无服务器函数，再由 Yandex Cloud Postbox 将通知发送到 IndexResearch 工作邮箱。完整请求内容不应写入常规技术日志。

保存期限

通信记录会在回复和后续沟通合理所需的时间内保存在工作邮箱中。除非法律或合法权益保护要求继续保存，用户可以要求删除其数据。

技术服务提供商

网站托管、表单处理和邮件投递可能使用 GitHub 与 Yandex Cloud 基础设施，只传输完成相关技术操作所需的数据。

用户权利

用户可以请求查询、更正或删除已提交的数据，也可以通过 research@indexresearch.ru 撤回同意。

提交表单同时表示确认 个人数据处理同意书。
