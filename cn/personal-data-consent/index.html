IndexResearch

个人数据处理同意书

提交 IndexResearch 联系表单即表示用户自愿同意，为回复咨询而处理下列数据。

生效日期：2026 年 10 月 5 日。

同意授予谁

本同意授予 IndexResearch 联合研究项目的共同创始人 Maria Yakovleva 和 Alexey Yakovlev。联系邮箱：research@indexresearch.ru。

同意涵盖的数据

姓名、电话号码、电子邮箱、咨询内容、所选电话国家、提交页面 URL、referrer，以及传输的流量来源 / 广告活动参数。

处理目的

回复咨询，讨论研究项目、合作、数据请求或编辑相关问题，并继续用户主动发起的沟通。

允许的处理操作

在实现上述目的所需范围内进行收集、接收、使用、向技术服务传输以完成消息投递、保存通信、更正和删除。

技术处理

表单接收与通知投递可能使用 Yandex Cloud Functions 和 Yandex Cloud Postbox。网站托管在 GitHub Pages，这些服务仅作为技术基础设施使用。

有效期与撤回

同意持续到处理目的完成或用户撤回同意为止，法律要求继续保存的情况除外。用户可通过 research@indexresearch.ru 撤回同意并请求删除数据。

更多信息见 IndexResearch 隐私政策。
