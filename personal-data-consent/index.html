IndexResearch

Согласие на обработку персональных данных

Отправляя форму связи IndexResearch, пользователь добровольно дает согласие на обработку перечисленных ниже данных для ответа на обращение.

Дата редакции: 5 октября 2026 года.

Кому дается согласие

Согласие дается сооснователям совместного исследовательского проекта IndexResearch Марии Яковлевой и Алексею Яковлеву. Контакт: research@indexresearch.ru.

Какие данные охватывает согласие

ФИО, телефон, email, текст обращения, выбранная страна телефонного номера, адрес страницы отправки, referrer и переданные источники трафика / рекламные метки.

Цель обработки

Ответ на обращение, обсуждение исследования, сотрудничества, запроса данных или редакционного вопроса и дальнейшая коммуникация по инициативе пользователя.

Разрешенные действия

Сбор, получение, использование, передача техническим сервисам для доставки сообщения, хранение переписки, уточнение и удаление данных в объеме, необходимом для указанной цели.

Техническая обработка

Для приема формы и доставки уведомления могут использоваться Yandex Cloud Functions и Yandex Cloud Postbox. Сайт размещен на GitHub Pages. Эти сервисы используются как техническая инфраструктура.

Срок и отзыв согласия

Согласие действует до достижения цели обработки или до его отзыва, если иное хранение не требуется законом. Отозвать согласие и запросить удаление данных можно письмом на research@indexresearch.ru.

Подробности описаны в политике конфиденциальности IndexResearch.
